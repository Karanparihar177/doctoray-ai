How the AI service works with our backend

The Node.js backend stays the front door and the source of truth. The FastAPI service does the heavy processing and hands back drafts. FLAC and Opus are shown as one step, "compressed audio".

Decisions so far

TopicStatusDecision
RolesDecidedNode.js backend owns auth, appointments, MySQL and the final record. The AI service only processes and returns drafts.
AuthDecidedOne token for the Node.js backend and the AI service. The AI service verifies it on every call.
DatabaseDecidedThe existing MySQL holds jobs, drafts and confirmed notes.
Audio formatDecidedFLAC and Opus are one "compressed audio" step. Pick the format from transcription quality and the provider's file limit.
Draft, then confirmDecidedEvery AI output is a draft. Only the doctor's explicit confirm makes it final.
Keep it simpleDecidedNo message queue, vector DB, RAG or agents for now.
Job status sync and presigned URLLaterThe backend creates the job and a short-lived S3 URL. The AI service reports status back. This replaces the open HTTP downloader.
Who writes to MySQLOpenRecommended: only the backend writes. The AI service returns JSON through a callback or the backend polls it. This keeps one writer and one set of rules.
Speech-to-text and LLM providersOpenTest mixed Arabic and English first. Check privacy, data retention and processing location before sending real audio.
Doctor and patient labelsOpenDiarization gives "Speaker 1 and 2" only. Let the doctor confirm who is who in the review step.
Unsupported claimsOpenSchema checks cover shape, not truth. Add a source quote or timestamp per claim so the doctor can verify it quickly.
RetentionOpenSet when temporary audio, transcripts and drafts are deleted.

Rules the flows enforce

Drafts only

The AI never writes a final record. The doctor confirms in step 10 before step 11.

Source stays intact

The recording and the patient's original text are kept. Generated content is stored beside them, never over them.

No invented clinical content

No diagnosis, medication or advice that was not stated. Missing or unclear fields are flagged for the doctor.

The browser never calls the AI service

Only the backend does, with the shared token and a short-lived S3 URL.
